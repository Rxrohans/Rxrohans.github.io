Oscilloscope plotting tool

A small web app that turns the messy CSV files a digital oscilloscope exports into readable voltage plots.

Context
Personal project
When
2024
Tools
Python, Pandas, Matplotlib, Streamlit
Links
Source on GitHub

Problem

Digital storage oscilloscopes export readings as CSV files with extra header rows and inconsistent columns. Plotting them meant cleaning each file by hand.

What it does

  • Upload a raw CSV export from the oscilloscope.
  • The app cleans the file and plots voltage against time.
  • Useful for quick signal checks while debugging circuits.
